
## 1. 4 Bias — Was LLM glätten

| Bias                                  | Beispiel             | Gemini sagt...                   | Graph zeigt...                                    |
| ------------------------------------- | -------------------- | -------------------------------- | ------------------------------------------------- |
| **Unsicherheit wird Gewissheit**      | Todesurteil 30. März | "Verurteilt am 30. März"         | 18× `reported`, 0× `direct`, 1× Widerspruch (29.) |
| **Lücken werden unsichtbar**          | Karlsruhe-Lücke      | Erwähnt ohne Kontext             | 6 Tage Differenz, 14 CH-Quellen = Stille          |
| **Informelle Netzwerke verschwinden** | Wer interveniert?    | "Der Bundespräsident"            | Schulthess, Meylan, Bornand (14 Mikro-Aktionen)   |
| **Opfer werden passiv dargestellt**   | Elisabeth aktiv?     | "Sie konnte zahlen" (Kuriosität) | Aktiver als ihr freier Anwalt                     |

## 2. 3 Argumente — Warum Graph?

| Argument                 | Prompting (LLM)              | Graph + Historian                            |
| ------------------------ | ---------------------------- | -------------------------------------------- |
| **Exploration**          | Antwortet auf Fragen         | Zeigt, was man nicht zu suchen wusste        |
| **Ehrlichkeit**          | Fasst "neutral" zusammen     | Dokumentiert explizite Entscheidungen        |
| **Offene Wissenschaft**  | Chat verloren                | Nachvollziehbar, reproduzierbar, teilbar     |

---

## 3. Fazit

> 💬 **Graph bewahrt. LLM glättet.**
> **Der Graph bewahrt**, was das LLM glättet.
>
> **Der Graph zeigt**, was das LLM versteckt.
>
> **Der Graph dokumentiert**, was das LLM vergisst.
